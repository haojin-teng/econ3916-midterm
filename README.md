# Do More Indebted Governments Pay Higher Yields?

## Question

Across 24 OECD countries, 2000–2024, is higher government debt (% of GDP) associated with higher 10-year government bond yields, holding inflation, growth and the current account constant?

## Data

10-year yields from FRED (OECD Main Economic Indicators); debt, current account, growth and inflation from the IMF World Economic Outlook, October 2026. Downloaded 2026-11-08 and saved in `data/`.

## How to run

Open `econ3916_midterm.ipynb` in Colab and choose *Runtime › Run all*. The data are read from this repository, so no API key is needed.

## Headline finding

In the same year, 10 points of GDP more debt go with a yield 0.023 points higher (95% CI −0.020 to +0.067, N = 599); within a country over time, +0.278. Both are conditional associations, not causal effects.
